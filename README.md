# 🧮 Age Calculator

This is a simple and interactive web application that allows users to calculate their exact age in years, months, and days by selecting their date of birth.

## 🔧 Tech Stack

- **HTML5** – Structure of the web page  
- **CSS3** – Styling and responsive layout  
- **JavaScript** – Age calculation logic and user interaction

## ✨ Features

- Real-time age calculation
- Highlights your age in years, months, and days
- Prevents future dates from being selected
- Smooth and responsive UI with animations

## 🚀 How to Use

1. Clone or download this repository:
   ```bash
   git clone https://github.com/your-username/age-calculator.git
   ```

2. Open `index.html` in your browser.

3. Enter your date of birth and click **Calculate Age**.
